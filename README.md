# Телеграмм-бот для технической поддержки
бот для тех.поддержки, который отвечает на часто задаваемые вопросы пользователей, предоставляет решения проблем и направляет запросы к специалистам при необходимости.

## План:
***1. Автоматический ответ на часто задаваемые вопросы пользователей.***

***2. Интеграция с базой данных - нужно хранить все запросы к специалистам в отдельной таблице.***

***3. Возможность обработки текстовых сообщений ( не обязательно).***

***4. Интуитивно понятный и привлекательный интерфейс для пользователей.***

***5. Есть документация по использованию бота для администраторов.***

## Инструменты для реализации:
> pyTelegramBotAPI
>
> SQLite/PostgreSQL (SQLAlchemy)

## Проект состоит из:
> Database
>
>Tg bot
>
> python 3.10+
